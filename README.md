# MAT PortfolioIQ

**AI-Powered Crypto Portfolio Health Analyzer**

MAT PortfolioIQ is a lightweight crypto portfolio intelligence dashboard built by **@phamthimat**.

It helps users quickly understand their portfolio through allocation analysis, risk assessment, diversification scoring, live market data, performance ranking, and actionable insights.

## 🚀 Key Features

- Portfolio Health Score
- Risk Level Analysis
- Diversification Score
- Concentration Risk Analysis
- Portfolio Balance Analysis
- Interactive Allocation Chart
- Binance Live Market Data
- 24h Portfolio Return
- Estimated 24h P&L
- Top & Worst Performer
- Portfolio Contribution
- Market Volatility Signal
- Data Coverage
- Actionable AI Insights

## 🤖 Agent / Workflow

MAT PortfolioIQ follows a simple portfolio intelligence workflow:

1. User enters their portfolio value.
2. User enters crypto assets and allocation percentages.
3. The Portfolio Health Engine evaluates diversification, concentration, and portfolio balance.
4. MAT PortfolioIQ retrieves live 24h market data from Binance.
5. The system calculates portfolio-weighted market performance and estimated P&L.
6. Assets are ranked by market performance and portfolio contribution.
7. The system generates an actionable portfolio insight based on the analysis.
